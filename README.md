# saberium-reels

Reels de Instagram de Saberium (@saberium.studio). Repositorio público.

- `motor/`: biblioteca que monta los vídeos. Instrucciones en `motor/README.md`.
- `videos/NN-nombre/`: guion, voz y escenas de cada vídeo.
- `reels/`: los MP4 finales, con la fecha de publicación en el nombre. El enlace directo de aquí es el que se pasa a Instagram.
- `voz/`: locuciones antiguas (desde el vídeo 03, la voz va dentro de la carpeta del vídeo).
- `assets/`: logo y capturas de las webs reales (Amperiza, Atlantis Charters, The Barber Kingdom).
- `codigo/02-la-puerta/`: código del vídeo de la puerta, hecho antes del motor. Se guarda como ejemplo.
